# Addendum projectile — Super Wizard

`super_wizard` branches from the captured primary target. The 40% secondary
damage is primary evidence; ten total victims and the 3-tile base-range proxy
are versioned secondary/derivation assumptions. Every branch is a normal
serialised logical T+10-ms projectile, selected by distance to the primary and
then entity ID. The public sources do not establish true radius, cap,
eligibility, travel, collision or tick order, so this remains partial.
